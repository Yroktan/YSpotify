# YSpotify

Скачать: [Windows 0.8.3](https://github.com/Yroktan/YSpotify/releases/tag/v0.8.3) · [Android 0.1.0 — предварительная сборка](https://github.com/Yroktan/YSpotify/releases/tag/v0.1.0-android).

Клиент Spotify Free для Windows x64: собственный интерфейс Windows Forms, зелёная тема и контур Уцухо. Музыка поступает с Spotify через штатный Widevine; реклама и ограничения аккаунта определяются Spotify.

В версии0.8.2 исправлена загрузка избранного с недоступными песнями: страницы дочитываются по исходным записям и totalCount. Неполный ответ не заменяет сохранённый список; обновление сохраняет текущую позицию прокрутки.

В Windows 0.8.3 вкладка «Рекомендации» открывает подборки Spotify «Для тебя». Страница загружается по запросу, после чтения подборок её окно закрывается. Через меню «Поделиться» можно передать ссылку на трек или плейлист в Telegram, WhatsApp или скопировать её. Переписка ведётся в выбранном мессенджере.

Android-порт находится в [android/](android/README.md). Это отдельный нативный интерфейс с фоновым плеером; статус проверки мобильной сборки указан в его документации.

## Запуск и управление

Распакуй весь переносимый архив и запусти YSpotify.exe. Нужны Windows 10/11 x64, .NET Framework 4.8 и доступ к Spotify. Для воспроизведения не требуются установленный браузер, Node.js и отдельный сервер: подписанный аудиодвижок входит в сборку. Получателю не нужен аккаунт Castlabs EVS.

Первый вход открывается в отдельном профиле Firefox, если он установлен, либо в окне включённого движка. В Firefox доступен обычный вход через Google. После входа нажми «Я вошёл». Обычный профиль Firefox приложение не меняет.

- Enter в поиске загружает результаты. ▶ у трека запускает его одним нажатием. Двойной щелчок и Enter на строке также работают.
- «Любимое» и «Плейлисты» открывают библиотеку. Списки кэшируются на диске и обновляются через Spotify; каталог загружается постранично.
- Правый щелчок по треку открывает избранное и добавление в плейлист. Удаление из открытого плейлиста требует UID строки и разрешения Spotify.
- Внизу — фиксированная обложка, название, автор, пауза, стрелки и громкость. Длинные строки обрезаются многоточием. Доступность действий учитывает ответы Spotify.
- Перемешивание и повтор управляют выбранным списком внутри клиента. Стрелка назад возвращает предыдущую песню либо начинает текущую заново после первых трёх секунд.
- Discord по просьбе пользователя выключен и отложен.

У кнопок воспроизведения и стрелок есть эффект нажатия. Кнопка возле открываемого трека и нижний плеер показывают загрузку. Колесо работает над списком даже при фокусе в поиске; при перетягивании бегунка обновления объединяются, обложки читаются и уменьшаются в фоне.

## Данные и устройство

Окно нативное. Звук обслуживает минимальный документ MSE/EME в Castlabs Electron for Content Security 45.2.1+wvcus. Полная страница Spotify кратко открывается при штатном обновлении собственного сеанса и затем закрывается. Это не полностью нативный аудиодвижок.

Данные: %LOCALAPPDATA%/YSpotify. Сеанс и cookies только собственного профиля приложения защищены Windows DPAPI для текущего пользователя. Пароль клиентом не сохраняется. Токен автоматически обновляется; при отзыве входа самим Spotify понадобится повторная авторизация. Кэш библиотеки содержит пользовательские метаданные и обложки, а не офлайн-копии музыки.

## Сборка и проверки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1 --layout-only
.\YSpotify.exe --self-test --endurance-test
```

Тесты воспроизведения используют настоящий аккаунт и включают музыку. `test-mini.ps1 --latency-only` измеряет пять запусков, этапы сетевой загрузки, паузу и память; без флага проверяет управление и полный трек с автопереходом. Перед такими тестами закрой основное окно: они используют собственный профиль приложения. `test.ps1` без аргументов дополнительно проверяет старый Firefox/BiDi backend в отдельном тестовом профиле. `--design-preview` открывает демонстрационный макет.

Исходная сборка движка: prepare-player.ps1, затем производственная VMP-подпись официальным EVS по player/SOURCES.md. Подписанный runtime/ECS/electron.exe нельзя изменять. VMP и подпись издателя Windows — разные вещи.

package.ps1 собирает исходники по явному списку и переносимый архив со всем runtime. Профили, cookies, пароли и настройки EVS в архивы не добавляются. Бинарный runtime в исходники не включается.

Замеры и ограничения описаны в PERFORMANCE.md. Полное совпадение со всеми функциями официального Spotify не заявляется; внутренние API могут меняться. Проект не связан со Spotify AB.
